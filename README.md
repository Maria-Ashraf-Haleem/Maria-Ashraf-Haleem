## Projects

### Mero Restaurant - Full Stack Restaurant Management System

**Full-Stack ASP.NET Core MVC Web Application** using **C#, Entity Framework Core, SQL Server, ASP.NET Core Identity, Razor Views, HTML, CSS, Bootstrap, and JavaScript**

A complete restaurant ordering and management system that provides both a customer-facing website and an admin dashboard.

**Main Features:**

- Customer registration, login, and logout
- Role-based authorization using ASP.NET Core Identity
- Modern restaurant home page and menu page
- Food item browsing with images, categories, descriptions, and prices
- Customer order creation with quantity, delivery address, and notes
- Customer order tracking through "My Orders"
- Admin dashboard for monitoring restaurant activity
- CRUD operations for categories
- CRUD operations for food items
- Admin order management and status updates
- SQL Server database integration using Entity Framework Core
- Clean MVC architecture with Services, Models, ViewModels, Controllers, and Razor Views

**Architecture Highlights:**

- MVC pattern for clean separation of concerns
- Service layer for business logic
- Entity Framework Core for database operations
- SQL Server database managed through SQL Server Management Studio
- Identity seeding for default roles and admin account
